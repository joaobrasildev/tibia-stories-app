Amazon Shield — pesquisa completa

Vou ser direto e criterioso: o Amazon Shield segue exatamente o mesmo padrão estrutural dos outros itens do “set Amazon”.
Ele nunca foi um rare real, não possui quest conhecida e sempre foi obtido via loot.
Ainda assim, ele tem uma história interessante — não pela mecânica, mas pela evolução da percepção dos jogadores ao longo do tempo.

Introdução

O Amazon Shield é um escudo leve associado às criaturas Amazons.

Características documentadas:

Defense: 15
Peso: ~18 oz
Drop: Amazons
Vocação: todas

(tibiawiki.com.br
)

Ele sempre foi um item de baixo/médio nível, sem efeitos ocultos.

Existe ou existiu quest para o Amazon Shield?

➡️ Não existe nenhuma quest documentada envolvendo o Amazon Shield.

Não aparece como recompensa em nenhuma wiki consolidada
Não há registro em changelogs
Não existe relato confiável de descoberta de quest

Conclusão direta:

➡️ Sempre foi obtido exclusivamente via loot de criaturas

Origem do item

O Amazon Shield foi introduzido junto com:

Amazon Armor
Amazon Helmet
criaturas Amazons

Ou seja:

➡️ nasceu como parte de um conjunto temático comum

Não há qualquer evidência de:

criação via GM
evento especial
distribuição limitada
Como era obtido no passado

Desde sua introdução:

➡️ dropado por Amazons

Mas o contexto histórico muda a interpretação:

Nos primeiros anos do Tibia
poucas áreas com Amazons
respawns limitados
pouca informação sobre loot

Resultado:

➡️ o item era menos acessível na prática

Quem descobriu o item

Não existe registro de “descoberta”.

Motivo:

➡️ sempre foi item comum

Diferente de itens como:

Thunder Hammer (eventos)
Blessed Shield (GM reward)

O Amazon Shield simplesmente apareceu como parte do jogo.

Quando se tornou raro

Aqui está o ponto mais importante:

➡️ o Amazon Shield nunca se tornou raro por mecânica

Mas sofreu o mesmo fenômeno dos outros itens Amazon:

Raridade por desuso

Com o tempo:

perdeu utilidade prática
foi substituído por escudos melhores
jogadores deixaram de caçar Amazons

Resultado:

➡️ menor circulação no mercado

Por que ele ganhou valor (mesmo sendo comum)
1. Set completo

O Amazon Shield faz parte de um dos poucos sets clássicos:

Amazon Helmet
Amazon Armor
Amazon Shield

Isso aumentou o valor para colecionadores.

2. Nostalgia

Foi utilizado por muitos jogadores iniciantes.

3. Estética

Visual único e facilmente reconhecível.

Forma de obtenção hoje

Hoje o item continua sendo:

➡️ drop normal de Amazons

Ou seja:

não foi removido
não virou unobtainable
continua acessível

Mas:

➡️ pouco farmado → menor oferta

Mitos sobre o Amazon Shield

Mesmo sendo simples, ele acumulou alguns mitos.

Mito 1 — bônus de set

Teoria:

usar o set completo de Amazon daria:

bônus de defesa
ou algum efeito oculto

➡️ nunca comprovado

Mito 2 — ligação com quest secreta

Rumores diziam que o set fazia parte de:

uma quest escondida
possivelmente envolvendo NPCs femininas ou ilhas

➡️ nunca confirmada

Mito 3 — variações raras

Alguns jogadores acreditavam que:

existiam versões raras do escudo
ou drops especiais

➡️ não existe evidência

Diferença crítica (para o seu app)

O Amazon Shield não é raro por sistema.

Ele é:

➡️ um item comum que ganhou valor simbólico
